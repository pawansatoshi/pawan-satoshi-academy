# Code of Conduct

## Our Values

- Learn before earn.
- Verify before trusting.
- Respect everyone.
- Help beginners.
- Share knowledge, not hype.

## Expected Behavior

- Be respectful in all repository interactions (issues, pull requests,
  discussions) and in the Discord community.
- Assume good faith, especially with beginners asking basic questions.
- Use official sources when making technical claims.
- Report scams, security issues, or abuse instead of engaging directly.
- Keep discussions on topic.

## Unacceptable Behavior

- Harassment, hate speech, or discrimination of any kind.
- Scams, phishing links, or malware in any contribution.
- Impersonation of staff, mentors, or other members.
- Sharing NSFW or illegal content.
- Guaranteeing investment returns or giving financial advice as if it
  were certain fact.
- Asking anyone for passwords, seed phrases, or private keys.

## Enforcement

Violations in the repository (issues, PRs, discussions) will be
moderated by maintainers — this can include comment removal, PR
rejection, or contributor blocking for repeated violations.

Violations in the Discord community follow the moderation process in
`docs/modules/moderation-automod.md` and the Discord server's own
`#rules`.

## Reporting

Report violations via:
- A private message to a moderator/admin in Discord, or
- GitHub's report feature on the relevant issue/PR, or
- The process in `SECURITY.md` for security-related conduct issues

## Appeals

Warnings and bans (in Discord or the repository) have a documented
appeal process reviewed by staff — contact an Admin via DM to request
review.
