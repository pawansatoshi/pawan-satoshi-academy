# Project Constitution

Pawan Satoshi Academy is governed by a small set of product and security principles.

## 1. Free-first access

Learning, quizzes, assessments and graduation should remain available without requiring paid services. Optional paid infrastructure must never become a mandatory learner dependency.

## 2. Education before promotion

Content should teach concepts, risks, verification methods and responsible use. The Academy must not present educational material as financial advice or guaranteed outcomes.

## 3. Security by default

Secrets remain environment-only. Recovery phrases, private keys, passwords, authentication codes and bot tokens must never be requested or stored by the Academy as ordinary learner content.

## 4. Least privilege

Discord permissions and application capabilities should be limited to what each feature actually needs. Administrator access is not a substitute for correctly configured permissions.

## 5. Progressive learning

Practice is for learning; required chapter assessments and the final examination are progression gates. Learners should understand the material rather than merely complete commands.

## 6. Source-aware content

Technical claims should be separated from assumptions. Learners are encouraged to verify current documentation before acting on network, wallet, payment or application instructions.

## 7. Non-destructive operations

Automation must not silently delete existing community resources or third-party integrations. Changes to live Discord infrastructure should be reviewable before application.

## 8. Privacy and data minimization

Store only information required for Academy functionality, keep credentials out of source control, and restrict management/export functions to authorized roles.
