# Mobile Quickstart

Pawan Satoshi Academy is designed to be usable from an Android phone as well as a desktop.

## Website

Open the GitHub Pages site and choose **Start learning**. The curriculum opens in the Academy lesson reader and the lessons are served from the repository's Markdown corpus.

## Discord bot

The Discord bot runs on the configured runtime and keeps its application secrets in environment variables. Do not paste the Discord token, database credentials or other secrets into GitHub files or Discord messages.

After a deployment, verify `/health`, then test `/profile`, `/ask`, `/game knowledge`, certificate verification and the community support flow in a controlled channel.

## Learning flow

1. Start with Orientation.
2. Progress through Classes 1–12.
3. Use practice quizzes for learning.
4. Complete required chapter assessments to unlock later chapters.
5. Complete the final examination for graduation.
6. Use the certificate ID to verify a completed certificate.

## Security

Never share a seed phrase, private key, password, authentication code or Discord bot token. Treat unexpected wallet-signing requests, recovery-phrase requests and urgent credential requests as security warnings.
