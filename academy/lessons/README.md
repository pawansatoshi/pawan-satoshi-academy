# Pawan Satoshi Academy Lessons

The lesson corpus is the canonical learning layer behind the website and retrieval-first AI helper. Each class lesson contains objectives, core concepts, practical guidance, safety notes, and a short self-check.

## Curriculum

- Orientation — how the Academy works, digital citizenship and learning workflow
- Class 1 — Internet Basics & Digital Literacy
- Class 2 — Cyber Security & Password Safety
- Class 3 — Digital Payments
- Class 4 — Git & GitHub
- Class 5 — Linux
- Class 6 — Programming Basics
- Class 7 — AI & Prompt Engineering
- Class 8 — Bitcoin & Blockchain
- Class 9 — Ethereum
- Class 10 — Base & Stablecoins
- Class 11 — DeFi & Wallet Security
- Class 12 — Web3, Testnets, Ambassador Programs & Community Management
- Graduation — synthesis, responsible practice and final examination preparation

Lessons intentionally explain principles rather than encourage speculative activity. References are included only where the Academy has a stable official source.
