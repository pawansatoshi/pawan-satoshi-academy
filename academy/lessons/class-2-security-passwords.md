# Class 2 — Cyber Security & Password Safety

## Objectives
Understand common attack surfaces, authentication, phishing, malware, least privilege and strong credential practices.

## Security model
Security is a process of reducing risk, not achieving perfect safety. Identify assets, threats, vulnerabilities and likely impact. Use layered controls: updates, strong authentication, backups, access control, monitoring and recovery plans.

Phishing manipulates people into revealing information or performing an unsafe action. Malware can steal data, damage systems or establish persistence. Social engineering works even when software is patched, so verify unusual requests through an independent channel.

## Passwords and authentication
Use a unique password for every important service and store it in a reputable password manager. Prefer passkeys or phishing-resistant multi-factor authentication when supported. Never reuse a password across email, finance and developer accounts.

A seed phrase is not a normal password. It is a recovery secret that can control a wallet. Anyone who obtains it may be able to control the associated assets; legitimate support staff do not need it.

## Incident response
If credentials are exposed, revoke sessions, rotate credentials, enable stronger authentication and review account activity. Preserve evidence before deleting suspicious messages or files when an incident may need investigation.

## Self-check
What does least privilege mean? Why is password reuse dangerous? What should you do first after discovering that a credential was exposed?
