# Class 1 — Internet Basics & Digital Literacy

## Objectives
Explain how the internet moves information, distinguish browsers from websites and servers, and use digital tools safely.

## Internet basics
A device connects to a network through local networking and an internet service provider. DNS translates human-readable domain names into network addresses. HTTP and HTTPS describe web communication; HTTPS adds transport encryption and server authentication through TLS.

A browser is a client application. A website is a collection of resources delivered by servers. A URL identifies a resource and can include a scheme, host, path and query parameters. Cookies and local storage can preserve state, but they are not substitutes for secure authentication.

## Digital literacy
Evaluate information by checking the source, date, author, supporting evidence and whether the claim is independently corroborated. Treat shortened links, unexpected downloads, fake login pages and urgent requests as warning signs.

## Practical habit
Before entering credentials, inspect the domain and use a bookmark for important services. Keep the operating system, browser and extensions updated and remove software you no longer trust.

## Self-check
Why does DNS matter? What is the practical security difference between HTTP and HTTPS? Which signals would make you distrust a login page?
