# Class 12 — Web3, Testnets, Ambassador Programs & Community Management

## Objectives
Understand Web3 application architecture, use testnets safely, contribute to programs responsibly and operate healthy communities.

## Web3
Web3 applications commonly combine wallet identity, smart contracts, decentralized infrastructure and conventional web services. The wallet is a user-controlled credential, not proof that every connected application is trustworthy.

## Testnets
A testnet is an environment used to test software and workflows without relying on production value. Testnet tokens should be treated as having no guaranteed monetary value. Never reuse production secrets simply because an application is labelled a testnet.

## Ambassador programs
A good ambassador contribution is measurable and useful: documentation, tutorials, bug reports, community support, translation or constructive feedback. Follow official rules, disclose conflicts and avoid spam or fabricated engagement. Do not promise rewards that the program itself has not promised.

## Community management
Healthy communities need clear rules, consistent moderation, escalation paths and transparent decisions. Track recurring issues, protect member privacy and distinguish criticism from abuse. Moderators should document consequential actions so decisions can be reviewed.

## Self-check
Why should testnet credentials be separated from production credentials? What makes an ambassador contribution useful? What evidence should a moderator record after a serious incident?
