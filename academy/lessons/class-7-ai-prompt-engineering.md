# Class 7 — AI & Prompt Engineering

## Objectives
Understand how modern AI systems generate outputs, how prompts shape behaviour, and how to evaluate AI responses.

## AI fundamentals
A language model predicts likely token sequences from context learned during training. It can produce useful explanations, code and transformations, but fluent language is not evidence of truth. Models may hallucinate, omit uncertainty or follow misleading context.

## Prompt engineering
A robust prompt defines the task, relevant context, constraints, output format and evaluation criteria. Ask for explicit assumptions and structured results when accuracy matters. For repeatable workflows, keep prompts versioned and test them against representative cases.

## Verification
Use authoritative sources for claims that affect money, security, law or production systems. Treat generated code as untrusted until reviewed, tested and run in an appropriate environment. Never paste private keys, passwords or confidential customer data into an AI tool without an approved security model.

## Self-check
Why can a confident AI answer still be wrong? Which prompt elements improve reproducibility? When should an AI-generated answer be independently verified?
