# Class 10 — Base & Stablecoins

## Objectives
Understand L2 networks, bridging concepts, stablecoin designs and operational risks.

## Base
Base is an Ethereum Layer 2 network designed to provide lower-cost transaction execution while inheriting security properties from Ethereum's settlement architecture. Users still need to select the correct network and understand which assets and bridges are supported.

## Stablecoins
A stablecoin attempts to maintain a target value, commonly against a fiat currency. Designs vary: fiat-backed reserves, crypto-collateralized systems and algorithmic mechanisms have different failure modes. A stablecoin's target is not a guarantee that its market price can never move.

## Practical risk model
Separate protocol risk, issuer/custody risk, bridge risk, smart-contract risk, liquidity risk and user-operation risk. Before moving funds, verify the network, token contract and official bridge or application. Never trust a token name alone.
