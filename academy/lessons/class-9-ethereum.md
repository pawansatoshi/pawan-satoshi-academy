# Class 9 — Ethereum

## Objectives
Understand accounts, transactions, smart contracts, gas and decentralized applications.

## Ethereum model
Ethereum provides a programmable state machine. Externally owned accounts use private keys; contract accounts execute code according to transactions and calls. A transaction can change state and consumes computational resources measured through gas.

Smart contracts are programs deployed to a blockchain. Once deployed, their behaviour is constrained by the code and protocol rules, so bugs can be difficult or impossible to repair without a migration mechanism. Auditing, testing and limited permissions are therefore essential.

## User safety
A wallet signature is an authorization action, not merely a login. Read what a wallet asks you to approve and understand token allowances and contract permissions. Use separate wallets for experimentation and high-value assets when practical.
