# Academy Content

Source-of-truth Markdown for every lesson, deployed to the website by
the Pages build. Structure:

- `orientation/` — Orientation content
- `classes/` — Class 1 through Class 12 lessons
- `graduation/` — Capstone + final exam + career guidance content
- `subjects/` — Reference material organized by subject, linked from
  classes (this is what backs the Discord Academy Hub forum threads)

Populated in Phase 3 of the implementation plan.
